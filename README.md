# Image-PRocessing-System.
This is the project of Data Structure and algorithms of 3rd semester BS(CS). We are student of Bahria University and create this sytstem of image processing using DSA concepts.
 Image Processing & Compression System
C++ | Lossless Compression | GUI | No External Libraries
🔹 A complete image processing & compression system built from scratch in C++
🔹 No external image processing libraries used – pure data structures & algorithms

✨ Features
✅ Template-based Matrix Class – reusable & flexible

✅ RGB Image Representation – pixel-level manipulation

✅ Core Operations – Grayscale, Brightness, Scaling, Edge Detection, Flip (H/V)

✅ Lossless Compression – Run-Length Encoding (RLE)

✅ File Handling – Read/Write PPM images

✅ Performance Optimized – O(n×m) time & space complexity

✅ Simple GUI – user-friendly interaction
